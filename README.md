# Allanie Aloe website

A responsive artist website made with plain HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser. Optional local server: `python -m http.server 8000` then visit `http://localhost:8000`.

## Check before publishing
- The email was supplied as `allaniealoegmail.com`; it appears to be missing `@`. It is shown exactly as provided. Update both the visible address and `mailto:` link once confirmed.
- Confirm the Facebook, Instagram and TikTok URLs resolve to your official profiles.
- Replace the abstract artwork and upcoming-music placeholder with your approved artist photos, actual releases, streaming links and videos.
- The phrase “The greatest singer of our time” is used as a self-promotional tagline, not a verified award or objective fact.

## Files
`index.html` page content · `style.css` visual design · `script.js` mobile menu and current year.
